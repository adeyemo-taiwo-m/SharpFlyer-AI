# AI copy evaluation set

The set contains 54 cases covering normal, adversarial, ambiguous, and optional Nigerian Pidgin tone inputs. It runs the same Zod schema and post-filter used by the service; provider calls are intentionally not made in CI.

The estimated provider cost per call is **not available until a provider and current price are approved**. The service records provider-supplied `costUsd` and `pricingCheckedAt`; no provider price is invented in this repository.
